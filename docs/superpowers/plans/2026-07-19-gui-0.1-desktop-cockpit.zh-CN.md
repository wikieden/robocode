**目标：** 交付 GUI `0.1.0-alpha.1`、`0.1.0-beta.1`、`0.1.0`：先用证据选择 Tauri 或 GPUI，再完成 D11 -> D4 -> D1 -> permission/D6 -> evidence/gate/apply/recovery 的双语、可换肤、可访问本地操作闭环。

**架构：** GUI 只通过 transport-neutral `CoreClient` 消费不可变 `frontend-contract-v1` checkpoint。`GuiCoreAdapter` 把有序 envelope 交给 Core canonical `RuntimeViewState`，遇 gap 请求 snapshot/replay。GUI 只拥有呈现状态。alpha 在独立 nested workspace 同场比较 Tauri/GPUI；只有选中的框架接入根 Cargo workspace。

**技术栈：** Rust 2024、`viden-core`、Task 4 选定的桌面框架、内置 `en`/`zh-CN`、`tokens.css`/`gui-kit.css`、共享 replay fixture、框架原生交互和截图测试。

## 全局约束

- 从明确给出的不可变 Core SHA 创建 `.worktrees/v3-gui-client` / `codex/v3-gui-client`；不得猜 SHA，也不得提前开始生产 GUI。
- GUI 独占 `apps/gui/**`。根 `Cargo.toml`、共享 fixture、`.github/**`、设计包文件需与 owner 串行。
- GUI Rust 只依赖 `viden-core`、GUI 自有 crate、框架/平台库；禁止直接依赖 runtime/provider/tools/permissions/session/workflows/context/config。
- 所有业务 mutation 都发送 `RuntimeCommand`；收到有序 `RuntimeEvent` 前不得显示成功。sequence gap 必须进入恢复并等待 snapshot/replay。
- alpha 两端重放同一 D1 fixture，实现 theme/density、composer/CJK IME、stream/tool row、approval、queue、cancel、history scroll、10k events、50k transcript rows。
- GPUI 任一 IME、a11y、三平台 build+launch、有界 transcript、无需长期 fork 硬门失败，即 no-go 并选择 Tauri。
- locale 为 `en`、`zh-CN`；fallback：请求 locale -> 同语言默认 -> `en` -> 可见 key。代码、路径、命令、标识符不翻译。
- 偏好：`skin=aurora|ice|mono|amber|phosphor`、`mode=dark|light|system`、`density=compact|regular|comfy`、`motion=system|reduced|full`。Amber/Phosphor 仅 dark；非法组合可见回退 Aurora dark/regular。
- `tokens.css` 是数值真源，`gui-kit.css`/`DESIGN-REF.md` 是组件语义真源。禁手抄色、禁 emoji；visible focus、reduced motion、非纯颜色状态表达是硬门。
- D1 真源：`docs/viden-design/Viden/GUI/Viden - 桌面驾驶舱 (GUI).html`；D11/D4/D6 用 `GUI/pages/` 对应文件。
- 每个 release manifest 必须记录 component/Core/schema/capability/design/catalog/token revision。
- `apps/gui/release-manifest.toml` 是机器可读的当前 manifest；`apps/gui/manifests/<version>.toml` 是每个 GUI release 的逐字节等价不可变快照。
