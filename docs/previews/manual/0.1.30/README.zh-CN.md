# Viden 0.1.30 人工 TUI 证据

English version: [README.md](README.md)

这些截图在 macOS 上采集，用于最终 0.1.x zero-bug gate。

## 覆盖范围

- `terminal-main-idle.png`：macOS Terminal 首次启动 idle 界面。
- `terminal-live-turn.png`：macOS Terminal active live-work 界面。
- `terminal-model-selector.png`：macOS Terminal model picker 界面。
- `iterm2-main-idle.png`：iTerm2 首次启动 idle 界面。
- `iterm2-live-turn.png`：iTerm2 active live-work 界面。
- `iterm2-model-selector.png`：iTerm2 model picker 界面。

Terminal 截图使用 ANSI 彩色预览。iTerm2 截图使用同一 deepseek 预览状态的纯文本版本；
原因是当前本机 iTerm2 profile 对 ANSI 彩色预览渲染对比度很低。布局、scrollback 和面板
几何仍由同一 preview state 覆盖。

这些截图没有渲染 API key 或 secret。
