# RoboCode 0.1.30 Manual TUI Evidence

Chinese version: [README.zh-CN.md](README.zh-CN.md)

Captured on macOS for the final 0.1.x zero-bug gate.

## Coverage

- `terminal-main-idle.png`: macOS Terminal first-launch idle surface.
- `terminal-live-turn.png`: macOS Terminal active live-work surface.
- `terminal-model-selector.png`: macOS Terminal model picker surface.
- `iterm2-main-idle.png`: iTerm2 first-launch idle surface.
- `iterm2-live-turn.png`: iTerm2 active live-work surface.
- `iterm2-model-selector.png`: iTerm2 model picker surface.

The Terminal screenshots use the ANSI color previews. The iTerm2 screenshots use
the same deepseek preview states in plain text because the current local iTerm2
profile renders the ANSI color preview with very low contrast; the layout,
scrollback, and panel geometry remain covered by the same preview state.

No API key or secret value is rendered in these screenshots.
