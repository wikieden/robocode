viden —— 看着一切的驾驶舱

三层来历叠在一个词里:拉丁语 vidēre(看,监督)、丹麦语 viden(知识)、你的 GitHub 账号 wikieden 的连读缩合。产品本质——operator 看着多个 agent 干活——直接长在名字里。全小写、五个字母、等宽字体里干净利落。

vidēre 拉丁语 · 看

supervise / video / evident 的共同词根。监督与证据 (evidence) 两大支柱,一个词根全占。

viden 丹麦语 · 知识

北欧工业设计的冷静气质,贴合「可靠工业感」;knowledge = 留痕、可恢复的会话记忆。

wi·ki·eden → viden

作者签名藏在名字里:wikieden 快读缩合。私人彩蛋,不影响外部叙事。

Logo · 字标与符号
