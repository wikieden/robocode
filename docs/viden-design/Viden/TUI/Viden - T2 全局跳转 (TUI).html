全局跳转 ⌃P · jump to anything

一个搜索条,模糊匹配任何 lane / session / 闸 / 命令 / 文件,一跳直达 —— 收编 ⌃L/⌃S 的统一入口。直接打字过滤,↑↓ 选,↵ 跳,esc 关;首字符用 sigil 限定类型(@会话 #闸 >命令 ~文件)。下面是可操作 demo —— 点输入框直接搜。

01

它收编了什么

one entry, many targets
⌃P统一入口

⌃L 切 lane、⌃S 切会话 仍保留(熟手直达),但 ⌃P 是不用记类型的总入口:一个搜索框找到一切并跳过去。

⌘跨 lane 找 session

会话散在各 lane 里。@弹幕 直接定位 L2·S3 二阶段弹幕密度,不用先切 lane 再翻会话条。

⏸顺手清闸

# 只看待办闸 / 问询,选中即进决策中心那一条 —— 跳转与"清队列"合一。

02

sigil 限定

type to filter · sigil to scope
(无) 全部:lane · 会话 · 闸 · 命令 · 文件 : 只 lane @ 只 session # 只 闸 / 问询 > 只 命令 ~ 只 文件
03

TUI 可行性

feasible · 而且是强项
≡就是个过滤列表

输入行 + List widget + fzf 式打分(Rust nucleo,fzf/telescope 同款)。ratatui 标配,纯文本键盘流 —— TUI 强项。

⛁数据源都在进程内

lane=daemon 注册表 · session=会话表 · 闸=队列 · 命令=静态注册,即时查;文件走 fd/ripgrep 异步索引。

⚡不卡 UI

输入防抖,大仓文件搜索异步流式回填;浮层 dim 背景,truecolor 高亮 / 256 降级。比 GUI 还轻。

定为规则原语:⌃P = 全局跳转,套用通用列表契约(↑↓/jk · ↵ · esc · 打字过滤),可跳转项标 ↗。它不取代 ⌃L/⌃S(熟手肌肉记忆),而是零记忆负担的兜底入口 —— 建议补进《TUI 交互规则》§03 全局和弦。
